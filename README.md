# WhatsApp Bot - Auto Resposta

Bot simples e eficiente para WhatsApp com sistema de respostas automáticas.

## Funcionalidades
- Respostas automáticas baseadas em palavras-chave
- Suporte a saudação, menu, FAQ
- Logs de conversas
- Fácil de customizar comandos e respostas
- Modo "amigável/profissional" para portfólio

## Tecnologias
- Node.js
- whatsapp-web.js (ou Baileys, dependendo da versão)
- qrcode-terminal (para autenticação)

## Como usar
1. Clone o repositório
   ```bash
   git clone https://github.com/TaylorReis-lab/whatsapp-bot.git
   cd whatsapp-bot
   ```
2. Instale as dependências
   ```bash
   npm install
   ```
3. Inicie o bot
   ```bash
   npm start
   ```
4. Escaneie o QR Code no terminal com seu WhatsApp
